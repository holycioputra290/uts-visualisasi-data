## 📌 Latar Belakang & Wawasan Utama (Key Insights)
1. **Dominasi Kategori:** Kategori *Clothing* dan *Accessories* menghasilkan total transaksi tertinggi dibandingkan kategori produk lainnya.
2. **Karakteristik Demografi:** Rentang usia 18–70 tahun memiliki persebaran transaksi yang relatif merata, dengan rata-rata pengeluaran per transaksi berkisar **$59.76**.
3. **Pola Pembayaran:** Pelanggan menggunakan berbagai metode pembayaran (*Credit Card, PayPal, Cash*) tanpa dominasi tunggal pada satu metode tertentu.
4. **Tingkat Kepuasan:** Rata-rata *Review Rating* berada di angka **3.75 / 5.0**, menunjukkan kualitas produk dan layanan yang cukup stabil.
